# Spammer

Spammer is a console tool for stress-testing the OTP delivery of SMS and call verification endpoints exposed by third-party services. It repeatedly triggers a phone number's verification flow across configured providers to help evaluate their request-rate limiting and abuse protections.

This project is intended strictly for authorized security testing in a safe, controlled environment. Any misuse is the sole responsibility of the person running it.
